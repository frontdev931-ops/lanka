# Вопросы для клиники (этап 1: уточнение требований)

Ответы нужны, чтобы выбрать первый отчёт и понять, что можно взять из Cliniccards.

## 1. Отчёты, которые собираются вручную
Для каждого из 2–3 самых частых отчётов:
- Как называется и для чего нужен (кто смотрит и какое решение принимает)?
- Как часто собирается (ежедневно, еженедельно, ежемесячно)?
- Сколько времени уходит на сборку?
- Из каких источников берутся данные (отчёты Cliniccards, свои таблицы, что-то ещё)?
- Какие столбцы и расчёты в итоговой таблице? (Пришлите пример файла; персональные данные пациентов можно заменить или убрать.)

## 2. Данные вне Cliniccards
- Какая информация ведётся только в таблицах (источник обращения, результаты звонков, комментарии)?
- Кто и как её заполняет?

## 3. Доступ к Cliniccards
- Какой тариф? Есть ли доступ к API или выгрузке данных?
- Кто в клинике может запросить доступ у поддержки Cliniccards?
- Какие функции (напоминания, рассылки, отчёты) в Cliniccards уже используются?

## 4. Работа с пациентами
- Как сейчас определяется, кому нужно позвонить (повторный визит, незавершённое лечение, давно не были)?
- Через какие каналы связи реально общаются с пациентами?
- Собираются ли согласия на рассылки и где они хранятся?

## 5. Масштаб и успех
- Сколько клиник, филиалов и сотрудников будут пользоваться системой?
- Какой результат через 2–3 месяца будет считаться успехом (например, «отчёты собираются за 10 минут вместо 3 часов»)?
